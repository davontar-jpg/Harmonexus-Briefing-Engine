Harmonexus Market Engine

Privacy policy

Effective November 2, 2026. Operator and privacy contact: davontarobinson@gmail.com.

Scope and information handled

This policy covers the Harmonexus Briefing Engine / Market Engine, its Streamlit dashboard, associated Google Sheet and Apps Script briefing workflow. It does not cover other Harmonexus applications.

The engine processes market observations, economic series, futures positioning, research tables, instrument scores, source timestamps, webhook events, briefing text and delivery logs. Configuration includes workbook/project identifiers, recipients and provider credentials. Account identifiers and authorization grants are used to operate the owner's authorized Google resources.

Google API access and purpose

Authorized Sheets access reads and writes the configured workbook, including source, score, audit and notification tabs. Apps Script authorization runs the engine, accesses external data providers, manages the project's scheduled triggers and sends email through MailApp. Deployment tools may access Google Drive file metadata and authorized Apps Script projects, deployments, Cloud project management and execution logs. The engine's email sender does not read the owner's inbox. The Streamlit dashboard reads workbook contents using its configured service account; it does not require visitors to provide Google credentials.

Storage and retention

Workbook records and Apps Script logs persist in the owner's Google resources. Some histories and caches have rolling row limits; other records remain until the operator removes them. There is no universal automatic deletion period. Script Properties and Streamlit secrets store configuration credentials; local deployment tools store OAuth credentials in their local configuration. This policy does not assert that every local credential store is encrypted.

External services and disclosure

Configured Telegram, email and optional Pushover destinations receive briefing contents and the destination identifiers necessary for delivery. When the optional OpenAI integration is enabled, structured analytical inputs such as scores, drivers and contradictions are transmitted for interpretation. External providers and hosting services process requests under their own applicable terms and privacy policies. The public legal pages are hosted on GitHub Pages, while the dashboard runs on Streamlit Community Cloud. Hosting providers may process ordinary request logs. No optional provider is implied to be active merely by being listed here.

The engine has no implemented advertising-data brokerage or sale workflow. Google user data is used to provide the authorized engine functionality; it is not an input for developing or training generalized AI models through this application. Access, use, storage and transfer of Google user data must comply with the Google API Services User Data Policy, including its Limited Use requirements.

Control, access and deletion

The owner can revoke Google access in Google Account permissions, disable configured integrations and remove retained workbook or application records. Revocation stops future authorized access but does not itself delete existing records or messages already delivered. Contact the operator to request access, correction or deletion of information handled by this deployment. No guaranteed response or deletion deadline is asserted.

Changes

Material changes to the engine's data practices should be reflected in this policy before those practices are adopted.
