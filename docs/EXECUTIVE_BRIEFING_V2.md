## Rendering, delivery and rollback

- A single snapshot feeds both plain-text Telegram editions and consolidated escaped HTML/plain-text email. The preview and dry run share that renderer. The 3,800 UTF-16-unit budget rejects over-budget mandatory content and omits only whole optional blocks; it does not truncate body text or use Telegram markup.
- The first normal run freezes one ET-day payload under the existing script-property authority. The legacy daily marker protects rollover and rollback. Edition I must be confirmed by Telegram before Edition II is attempted. A definite rejection allows that edition alone to retry on an authorized workday rerun; a timeout or ambiguous outcome blocks replay. The existing email recipient guard is unchanged. There is no automatic retry, new trigger, or second accepted email attempt. Provider acceptance is not reader receipt.
- Generate the immutable archive adapter with `node tools/build-executive-research.mjs <dashboard archive JSON> src/25_ExecutiveArchive.gs`. The normalized SHA-256 is also shown in Instrument Lab and the long briefing. Keep source candles private.
- Before sync, run `node tools/preview-executive-briefing.mjs <workbook ID> <private output directory outside Git> <previous full SHA>`. This reads the authorized workbook and runs the exact before/after source in a sandbox with no delivery capability. The full text and HTML are local release artifacts; never commit them.
- Production source publication uses `tools/sync-executive-source.mjs`: provide the verified existing project/workbook IDs in the process environment, then use `preflight`, `sync`, `verify`, and `dry-run`, with the exact prior and validated candidate commit IDs. It refuses unexpected source drift or scope. Revert on the source branch and publish the prior source to the **same bound project** if necessary. The source sync helper can also validate the inverse old/new inventory. Roll back the separate dashboard PR independently. Do not clear any daily idempotency markers, reinstall triggers or resend a delivered day.
